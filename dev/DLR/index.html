RPAToolkit.DLR

RPAToolkit.DLR.DLRGrid — Type
DLRGrid

omega (real frequencies), tau (imaginary times in (0, beta)) and tauc = beta - tau (kept exactly) of a discrete Lehmann representation at inverse temperature beta, cutoff euv and accuracy rtol. Build one with dlr_grid.

source
RPAToolkit.DLR.dlr_grid — Method
dlr_grid(beta, euv; rtol = 1e-12, degree = 24) -> DLRGrid

The DLR for functions with spectral support in [-euv, euv] at inverse temperature beta.

source
RPAToolkit.DLR.dlr_kernel — Method
dlr_kernel(t, tc, w) -> Float64

The dimensionless kernel $K(t, w) = e^{-wt}/(1 + e^{-w})$ with tc = 1 - t supplied exactly, evaluated without overflow for either sign of w.

source
RPAToolkit.DLR.matsubara_weights — Function
matsubara_weights(g::DLRGrid, n = 0) -> Vector{ComplexF64}

Weights $w_k$ with $\int_0^\beta e^{i\Omega_n\tau} F(\tau)\,d\tau \approx \sum_k w_k F(\tau_k)$, $\Omega_n = 2\pi n/\beta$ (bosonic), for any F the grid represents.

Each DLR basis function $K(\tau, \omega_l) = e^{-\omega_l\tau}/(1 + e^{-\beta\omega_l})$ integrates to $\tanh(\beta\omega_l/2)/(\omega_l - i\Omega_n)$; fitting F at the nodes and integrating the fit gives $w = K^{-T} I$.
