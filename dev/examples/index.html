Examples

The repository's examples/ folder has three lattices with nearest-neighbour hopping t = -1, an on-site Hubbard $U$ and a bare $1/r$ Coulomb tail:

examplelatticesites per cellpath
Squaresquare1Γ → X → M → Γ
Triangletriangular1Γ → M → K → Γ
Honeycombhoneycomb (graphene)2Γ → M → K → Γ

Each has a config, a script that builds the model and the interactions and runs both stages, and a Julia notebook that plots the results. Run one from the repository root:

julia --project=. -t 4 examples/Square/Square.jl

Writing your own

The square example, in full:

using RPAToolkit, TightBindingToolkit, JLD2, LinearAlgebra

function square_uc()
    uc = UnitCell([[1.0, 0.0], [0.0, 1.0]], 2)
    AddBasisSite!(uc, [0.0, 0.0])
    return uc
end

config = "examples/Square/Square.yml"
input = load_rpa_input(config)
mkpath(input["data_dir"])

# the free model: nearest-neighbour hopping, the same for both spins
uc = square_uc()
t1Param = Param(-1.0, 2)
AddIsotropicBonds!(t1Param, uc, 1.0, SpinMats(1 // 2)[4], "t1")
CreateUnitCell!(uc, [t1Param])
save(input["unitcell"]["julia"], Dict("unit cell" => uc, "parameters" => [t1Param]))

# the interactions: cases "Hubbard" and "Coulomb"
params, cases = hubbard_coulomb_interactions(square_uc(); onsite = 4.0, range = 3.0)
save(input["interactions"], Dict("parameters" => params, "values" => cases, "unit cell" => square_uc()))

BLAS.set_num_threads(1)
output = run_rpa(config; run_bare = true)

For another interaction, register your own Params with 4x4 channel matrices (see Conventions) and give each case a weight per Param in "values".

Reading the output

output = load(rpa_output_path(load_rpa_input("examples/Square/Square.yml")))
for (key, entry) in output
    println(entry["filling"], "  ", entry["Hubbard"]["critical strength"],
            "  ", entry["Hubbard"]["maximum reciprocal momentum"])
end

Hartree-Fock and the real-frequency RPA

examples/MeanField/ has two scripts, run in the package environment; see Collective modes and mean-field theory for what they compute.

scriptmodeloutput
Magnons.jlsquare-lattice Hubbard, Néel order on the √2×√2 cell, U = 4, 8, 12the transverse spin spectral function along Γ → X → M → Γ, with the Goldstone check and linear spin-wave theory overlaid
Plasmons.jldilute square-lattice metal with on-site U and $e^2/\varepsilon r$the loss function, the plasmon against $\sqrt{2\pi n e^2 q/m^*}$, and the particle-hole continuum
julia --project=. -t 8 examples/MeanField/Magnons.jl
julia --project=. -t 8 examples/MeanField/Plasmons.jl
