RPAToolkit.Bubble

RPAToolkit.Bubble.BandModel — Type
BandModel

A periodic-gauge hopping model: matrices[i] is t(R) for the lattice vector lattice_vectors[i] = offsets[i][1] a1 + offsets[i][2] a2, every bond's Hermitian conjugate included, and positions holds one position per (spinful) orbital. Build one with band_model.

RPAToolkit.Bubble.channel_operators — Method
channel_operators(n_orb; basis = nothing, directions = 0:3, spinful = true)

The operators the bubble is contracted with, ordered with the direction innermost: entry length(directions) (p - 1) + a is $M_p \otimes \sigma^{d_a}/2$ (spin inner, so orbital o spin s is index 2(o - 1) + s), with $M_p$ the basis matrices or, by default, the per-orbital densities $E_{pp}$. With spinful = false the operators are the $M_p$ themselves, for the spinless half of an SU(2) model.

RPAToolkit.Bubble.closed_basis_for_model — Method
closed_basis_for_model(bm; seed = "kanamori", bond_tol = 1e-3, resid_tol = 1e-6)

The symmetry-closed bilinear basis of an SU(2) model: the per-orbital densities (plus, with the default "kanamori" seed, every on-site off-diagonal bilinear) closed under the orbital representation D(g) of the lattice point group, measured from the bond vectors $d = R + \tau_b - \tau_a$. The Julia port of the bare stage's closed_basis_for_model.

RPAToolkit.Bubble.dynamic_bubble — Method
dynamic_bubble(bm, qs, omegas, k_size; beta, mu, eta, basis = nothing, nbins = 4000,
               spin = :auto) -> Matrix{Matrix{ComplexF64}}

The retarded bare bubble $\chi_0(q, \omega + i\eta)$, as chi[iq, iw], in the convention combine_chis gives the static bubble (it reduces to it at ω = 0; see the module notes), each a 4d × 4d matrix with the channel (N, X, Y, Z) innermost, d the number of basis operators (the orbitals, or the basis matrices). The k-sum runs over the k_size × k_size grid; the qs are arbitrary (a path), Cartesian.

nbins = nothing sums every pole exactly, $\sum (f_m - f_n) X X^\dagger / (E_n - E_m - \omega - i\eta)$, which costs length(omegas) per band pair. Otherwise the pole weights are first spread linearly onto nbins energies spanning the particle-hole range and the frequency sum is one matrix product: the error is O(bin width / eta), so keep the bin width a small fraction of eta.

spin = :auto uses the spinless bubble for an SU(2) model (band_spin_symmetry), whose four channels are then identical; spin = :full always sums the spinful one.

RPAToolkit.Bubble.lindhard_weight — Method
lindhard_weight(E1, E2, beta, mu) -> Float64

$(f(E_1) - f(E_2)) / (E_2 - E_1)$, evaluated as $\frac{\beta}{4}\,\frac{\sinh y / y}{\cosh x_1 \cosh x_2}$ with $x_i = \beta(E_i-\mu)/2$, $y = x_2 - x_1$: no cancellation for nearly degenerate levels (it becomes $-f'$ smoothly) and no overflow at large $\beta$. Never negative.

source
RPAToolkit.Bubble.particle_hole_edges — Method
particle_hole_edges(bm, qs, k_size; beta, mu, weight_tol = 1e-8) -> Vector{Float64}

The upper edge of the particle-hole continuum at each q: the largest $|E_m(k) - E_n(k-q)|$ over the band pairs whose occupation difference exceeds weight_tol, on the same k_size × k_size grid and (k, k - q) pairs as dynamic_bubble. This is the support of $\mathrm{Im}\,\chi_0(q, \omega)$ before the $\eta$ broadening, so a collective mode above it is undamped; reading the edge off the broadened bubble instead is biased upward by the Lorentzian tails.

RPAToolkit.Bubble.static_bubble — Method
static_bubble(bm, qs, k_size; beta, mu, ops, on_grid = false, eig_k = nothing)
    -> Vector{Matrix{ComplexF64}}

The static bubble $\mathrm{raw}_{ij}(q)$ (see the module notes) at each q, summed over the k_size × k_size grid k_grid, for the operators ops (channel_operators). on_grid = true declares that qs IS that grid, in its order, so k - q is looked up instead of diagonalized. Threaded over q.

source
RPAToolkit.Bubble.static_bubble_dlr — Method
static_bubble_dlr(bm, k_size; beta, mu, ops, euv = 20.0, rtol = 1e-12, matsubara = 0,
                  eig_k = nothing) -> Vector{Matrix{ComplexF64}}

The same bubble as static_bubble on its own k_size × k_size grid (in k_grid order), by the imaginary-time route:

raw_ij(q) = int_0^beta dtau sum_R e^{-iq.R} Tr[P(R, tau) O_j Q(-R, tau) O_i],
P(k, tau) = U diag(e^{xi tau} f) U',   Q(k, tau) = U diag(e^{-xi tau} (1 - f)) U',

with P and Q carried to real space by FFT and the tau integral done on a discrete Lehmann representation (dlr_grid, cutoff euv which must exceed the band span, accuracy rtol). O(Nk log Nk) per DLR node against the Lindhard sum's O(Nk^2). matsubara = n returns the bosonic frequency ``\Omegan = 2\pi n/\beta`` instead of 0.
