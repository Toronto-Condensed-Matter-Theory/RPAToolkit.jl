RPAToolkit.jl

RPAToolkit.jl computes the bare susceptibility of a tight-binding model, statically, $\chi_0(q, \Omega = 0)$, or at real frequency, $\chi_0(q, \omega + i\eta)$. It then solves the random phase approximation (RPA) for any set of two-body interactions: statically, to find which interaction strength first drives a charge, spin or orbital instability and at which ordering wavevector; dynamically, to follow collective modes such as magnons and plasmons (Collective modes and mean-field theory).

Features:

  • Lattices and hoppings are defined with TightBindingToolkit.jl. Any 2D unit cell with any number of sites and orbitals is supported.
  • Interactions are TightBindingToolkit Params whose bonds carry matrices in the (N, X, Y, Z) channels, so on-site, inter-site and long-range terms all go in the same way. A Hubbard + $1/r$ Coulomb builder is included (hubbard_coulomb_interactions).
  • Several interaction cases (e.g. "Hubbard" and "Coulomb") run against the same bubbles, over a scan of fillings or chemical potentials.
  • For multi-orbital models whose orbitals rotate into each other under the point group (an E doublet), the susceptibility and the Kanamori vertex can be put on a symmetry-closed bilinear basis, so $\chi$ stays covariant.
  • The critical strength, the leading eigenvector and its momentum, the RPA susceptibility, and the screened interaction $V + V \chi_\mathrm{RPA} V$ (effective_interaction).
  • The bubble is computed in Julia, threaded: the exact Lindhard sum (static_bubble), or an imaginary-time route with FFTs and a discrete Lehmann representation (static_bubble_dlr, dlr_grid) for large grids.
  • The real-frequency bubble (dynamic_bubble) and RPA (dynamic_rpa), spectral functions unfolded from supercells, and an Ewald-summed $1/r$ interaction (coulomb_2d).
  • Hartree-Fock bands from MeanFieldToolkit.jl, with the TDHF vertex of the same interaction (rpa_model, rpa_vertex).

Installation

using Pkg
Pkg.add(url = "https://github.com/Toronto-Condensed-Matter-Theory/RPAToolkit.jl")

Quick start

using RPAToolkit
run_rpa("examples/Square/Square.yml"; run_bare = true)

This needs the model and interactions files the config points to. The scripts in examples/ write them and then call run_rpa, so the shortest path is

julia --project=. -t 4 examples/Square/Square.jl

from a checkout of this repository. See Examples and Running a calculation.
