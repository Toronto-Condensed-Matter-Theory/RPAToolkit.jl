RPAToolkit.Pipeline.run_bare — Method
run_bare(config) -> String

The bare-susceptibility stage, in TRIQS.

Reads the model's "unit cell" from unitcell.julia, writes it in TRIQS form to unitcell.triqs, writes the resolved config (k-points as coordinates, absolute paths) to <output>_runtime_input.yml, and runs src/Bare/run_bare.py on it. That writes one <output>_beta=<beta>_mu=<mu>.npz per chemical potential and records the resolved mus and fillings back into the runtime file. Every mu is recomputed and overwritten.

The Python is launched with the config's triqs_environment if set, else the TRIQS_ENVIRONMENT environment variable, else python3 – e.g. mpirun -n 8 python3. Returns the runtime file.

RPAToolkit.Pipeline.run_rpa — Method
run_rpa(config; run_bare = false, plot = false, save_individual = false) -> Dict

The RPA stage. For every chemical potential of the bare stage and every interaction case in the interactions file, finds the critical strength with find_instability. Saves everything to rpa_output_path and returns it.

  • run_bare = true runs run_bare first.
  • plot = true saves chi_RPA along the k-path, at each of the config's strengths below the critical one, as <plots>_chi_beta=..._mu=..._interactionID=..._strength=....png.
  • save_individual = true also saves each instability on its own, as <output>_beta=..._mu=..._interactionID=<case>.jld2.

The (mu, case) pairs run in parallel over Julia threads (julia -t N); each pair is serial over momenta. Keep BLAS single-threaded (BLAS.set_num_threads(1)) so the two do not oversubscribe.

The output has one entry per mu, keyed "beta=<beta>_mu=<mu>", holding "mu", "beta", "filling", "triqs_data" (the bubble file), "combined_chis" and "combined_chis_path" (from combine_chis), "chi_orientation", "<case>_interaction" and "<case>_interaction_path" (the unit-strength V(q)), and "<case>" (the find_instability result). On the closed bilinear basis it also holds "bilinear_basis" and "basis_dim".
